🍔 HumHum – Food Delivery Platform

Excited to share a project I've been working on! 

I built HumHum, a scalable food delivery platform using ASP.NET Core MVC, applying Onion Architecture to keep things clean, testable, and maintainable — just like real-world production systems.

🧱 Architecture Highlights:

Clear separation between Domain, Services, Persistence & Presentation layers
Repository + Unit of Work pattern with Specification pattern for clean querying
SOLID principles applied throughout, with heavy use of Dependency Injection

⚙️ Tech Stack:

ASP.NET Core MVC + Razor Views (Bootstrap)
Entity Framework Core + SQL Server
Redis for caching & performance boost
FluentValidation for robust form handling
AutoMapper for clean object mapping
Cloudinary for media/image management

✨ Key Features:

Role-based authentication & authorization
Restaurant & product browsing
Real-time cart management
Smart checkout with delivery options
Order & payment tracking

This project pushed me to think about performance, scalability, and clean code from day one — from designing the database schema to implementing caching strategies with Redis.
